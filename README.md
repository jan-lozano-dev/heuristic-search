# heuristic-search

#### Disclaimer

En aquest repositori afegirem una carpeta anomenada "math-proofs". Hem decidit prendre un punt de vista més matemàtic de cara a fer l'activitat perquè les seves tres parts parteixen de la mateixa base matemàtica. Per amor a les matemàtiques i amb la intenció de fer un projecte el millor possible, afegirem una carpeta a partir de la qual farem el PDDL, el codi en Java i les respostes pertinents en la secció Markdown. Creiem que si demostrem bé l'arrel matemàtica del problema i la nostra heurística, farem un projecte molt més rigorós. De totes maneres, si aquesta carpeta fos innecessària o perjudicial per a la nostra nota —ja que estem prenent certa llibertat fent-la— pregem que sigui ignorada; el PDDL, el codi Java i el Markdown amb les respostes seran independents d'aquesta carpeta (/math-proofs). Gràcies i esperem que el professorat valori la nostra perspectiva diferent de la presentada a classe.
